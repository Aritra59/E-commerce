# E-commerce

Responsive fashion e-commerce landing page built as the final InternPe internship project.

**Live demo:** [aritra59.github.io/E-commerce](https://aritra59.github.io/E-commerce/)

## Features

- Responsive navigation with mobile menu toggle
- Hero section
- Feature highlights
- Featured products and new arrivals (static cards)
- Promo banners
- Newsletter and footer UI

## Tech Stack

- HTML
- CSS
- JavaScript
- Font Awesome
- Google Fonts

## Getting Started

```bash
git clone https://github.com/Aritra59/E-commerce.git
cd E-commerce
```

Open `index.html` in a browser.

## Notes

This repo contains the main landing page (`index.html`). Linked secondary pages (shop, blog, etc.) are not included in the repository.
